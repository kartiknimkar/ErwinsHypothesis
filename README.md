# Erwin's Hypothesis

A local statistics and scientific graphing application for macOS: data tables,
statistical analyses, curve fitting and publication-quality graphs, with a
clean, modern interface. Everything runs on your own computer.

**Status:** early development. See `ROADMAP.md` for planned features and
`HANDOFF.md` for current progress.

## Structure
```
backend/    Python statistics engine + local API (FastAPI)
frontend/   User interface (React + TypeScript)
docs/       Design notes
```
